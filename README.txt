EDEXCEL MATHS + FURTHER MATHS REVISION TRACKER
==============================================
Open index.html in any modern browser (double-click it). No install, no internet needed
for the tracker itself (links to videos/papers need internet).

Files
  index.html  page
  style.css   styling
  app.js      logic (dashboard, charts, saving)
  data.js     all chapters, sections and links taken from your two Excel trackers

Use
  - Switch between Maths and Further Maths at the top right.
  - On a book tab set Confidence (1-5), Last Reviewed and Notes. The date fills in
    automatically when you pick a confidence.
  - The Dashboard updates itself.
  - Ratings are saved in the browser you use. Use Export to back them up or move them to
    another device, and Import to load them back. Clearing browser data erases them.

Editing content: data.js is plain JSON-style data if you want to fix a title or link.
