EDEXCEL MATHS + FURTHER MATHS REVISION TRACKER
==============================================
Open index.html (double-click it) //  use the github repository page in any modern browser. No install, no internet needed
for the tracker itself however THE LINKS FOR THE VIDEOS / WORKSHEET PAGES DO REQUIRE INTERNET ACCESS


HOW TO USE
  - Switch between Maths and Further Maths at the top of the page
  - On a book tab set Confidence (1-5), Last Reviewed and Notes. The date fills in
    automatically when you pick a confidence.
  - The Dashboard is self updating
  - Ratings are saved in the browser you use. Use Export to back them up or move them to
    another device, and Import to load them back. CLEARING BROWSER DATA ERASES THEM.
